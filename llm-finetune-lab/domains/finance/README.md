# Domain: Finance

## Dataset

[`Josephgflowers/Finance-Instruct-500k`](https://huggingface.co/datasets/Josephgflowers/Finance-Instruct-500k) — 518,185 rows, Apache-2.0.


Field names were verified against the real dataset before this config was written, not assumed.

## Task

System + user turn → assistant answer. Financial analysis, terminology, and Q&A.

## Pipeline

```bash
make data DOMAIN=finance
```

Download → exact + near-duplicate dedup → decontaminate against mmlu → hold out 500 unseen examples. Runs locally, no GPU. Stats land in `results/`.

Then run `notebooks/quickstart_colab.ipynb` (already set to `DOMAIN = "finance"`) on a Colab GPU: baseline eval → train → identical eval → report.

## Eval

**Primary:** Held-out perplexity on unseen examples, plus the MMLU regression check.

Evals run for this domain:

- `holdout`: held-out split
- `mcq`: mmlu

MMLU is the general-capability regression check every domain runs — it catches a finetune that buys domain skill by degrading everything else.

## Results

`results/report.md`, generated by `python -m src.eval.report --domain finance`. Populated after a real Colab run — not before.

## Known limitations

- **No objective public benchmark here.** Finance answers are free text, so there's no execution or exact-match to score. Perplexity shows the model fit the domain's output distribution — it does not show the answers got more correct. Read it as 'training took effect', nothing stronger.
- Many rows carry an empty `system` field; those examples train without a system turn. That's intentional (matching the data) rather than injecting a synthetic prompt.
- 20k-row subsample of a 518k-row dataset, 1 epoch, rank-16 LoRA.
- Financial correctness is not verified by anything in this pipeline. Do not treat outputs as financial advice.
