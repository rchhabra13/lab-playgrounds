# Domain: Marketing

## Dataset

[`suehuynh/marketing-instruct-13k`](https://huggingface.co/datasets/suehuynh/marketing-instruct-13k) — 13,141 rows, Apache-2.0.


Field names were verified against the real dataset before this config was written, not assumed.

## Task

Marketing brief → ad copy, headlines, and campaign text.

## Pipeline

```bash
make data DOMAIN=marketing
```

Download → exact + near-duplicate dedup → decontaminate against mmlu → hold out 500 unseen examples. Runs locally, no GPU. Stats land in `results/`.

Then run `notebooks/quickstart_colab.ipynb` (already set to `DOMAIN = "marketing"`) on a Colab GPU: baseline eval → train → identical eval → report.

## Eval

**Primary:** Held-out perplexity, plus the MMLU regression check.

Evals run for this domain:

- `holdout`: held-out split
- `mcq`: mmlu

MMLU is the general-capability regression check every domain runs — it catches a finetune that buys domain skill by degrading everything else.

## Results

`results/report.md`, generated by `python -m src.eval.report --domain marketing`. Populated after a real Colab run — not before.

## Known limitations

- **Weakest domain in this repo, and worth saying plainly.** Marketing copy has no objective quality metric — no execution, no labels, no public benchmark. Perplexity is all there is, and good copy is precisely what perplexity fails to capture.
- The dataset's `original_completion` column is entirely `None`. Only the `enhanced_prompt`/`enhanced_completion` pair is usable, which this config uses. Caught by inspecting the data rather than trusting the column names.
- 13k rows, 1 epoch, rank-16 LoRA.
- If you want a defensible result here, the honest path is human preference ratings or a held-out A/B against the base model — neither of which this pipeline automates.
