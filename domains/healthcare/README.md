# Domain: Healthcare

## Dataset

[`FreedomIntelligence/medical-o1-reasoning-SFT`](https://huggingface.co/datasets/FreedomIntelligence/medical-o1-reasoning-SFT) — 19,704 (en config) rows, Apache-2.0.
Config: `en`.

Field names were verified against the real dataset before this config was written, not assumed.

## Task

Clinical question → chain-of-thought reasoning + final answer. The CoT is trained on deliberately, not dropped — it is the point of this dataset.

## Pipeline

```bash
make data DOMAIN=healthcare
```

Download → exact + near-duplicate dedup → decontaminate against medqa, mmlu → hold out 500 unseen examples. Runs locally, no GPU. Stats land in `results/`.

Then run `notebooks/quickstart_colab.ipynb` (already set to `DOMAIN = "healthcare"`) on a Colab GPU: baseline eval → train → identical eval → report.

## Eval

**Primary:** MedQA-USMLE 4-option accuracy — a real external medical benchmark, scored by next-token logits over A/B/C/D.

Evals run for this domain:

- `mcq`: medqa
- `mcq`: mmlu
- `holdout`: held-out split

MMLU is the general-capability regression check every domain runs — it catches a finetune that buys domain skill by degrading everything else.

## Results

`results/report.md`, generated by `python -m src.eval.report --domain healthcare`. Populated after a real Colab run — not before.

## Known limitations

- Training data is reasoning-style SFT; MedQA is multiple-choice. Gains there indicate medical knowledge, not clinical reasoning quality per se.
- Training examples overlapping MedQA are stripped before training (`decontaminate_against: [medqa, mmlu]`) — without that the benchmark would be measuring memorization.
- 15k rows, 1 epoch, rank-16 LoRA.
- **Not a clinical tool.** This is a benchmark exercise on public data. Nothing here is validated for medical use, and it must not inform patient care.
